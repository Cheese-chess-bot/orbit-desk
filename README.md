# Orbit Desk

AI-assisted reference prototype for learning how to build a browser desktop. This is not a finished eligible Stardance submission or a real operating system.

## Run
Open index.html in a browser, or serve dist with `python -m http.server 8000`.
No package installation, API key, or account required. Optional Google Fonts load from the internet; system fonts work without them.

## Files
- index.html: desktop, launchers and window containers.
- style.css: space theme, window styles, responsive layout.
- app.js: window manager and six apps. Notes, constellation points and theme use browser localStorage. The terminal recognizes a small fixed command list; it does not execute system commands.

## Features
Multiple draggable windows; close, minimize and maximize; desktop resizing; dock restoration; automatic note saving and text export; constellation drawing, undo and SVG export; focus timer; color themes; simulated terminal. On narrow screens, windows use nearly the full screen width and can move vertically.

## Manual test checklist
- Open two apps, drag both by their title bars, bring each to front.
- Minimize and restore through the dock; maximize and restore; close and reopen.
- Write a note, reload, reopen notes and verify text; export text.
- Place stars, undo, reload and verify persistence; export SVG.
- Start/pause/reset the focus timer; it keeps accurate elapsed time while the tab remains open, but does not survive reload.
- Use terminal help and open notes.
- Change an accent and reload.
- Test touch interaction on your actual phone before submission.

Validation performed: JavaScript syntax check; browser note persistence, multiple windows, close, drag, and constellation star creation. Physical mobile touch behavior and the full 25-minute timer were not tested.
